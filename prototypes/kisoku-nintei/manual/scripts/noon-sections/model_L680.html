2AI読取設定 — 推奨手順は次のとおりです。（1）一括インポート でテンプレートをダウンロードし、テキスト読取 と テーブル情報読取 タブそれぞれに、認識対象のフィールド名・テーブル列を表形式で一括登録します。（2）AI自動生成 をクリックし、各項目の プロンプト と 正解サンプル を自動生成します。（3）生成結果を確認し、必要に応じて手動で微調整します。項目を少数だけ追加する場合は + 項目追加 も利用できます。

続いて、設定アイコン → 読取モデル設定 で メインモデル（必須）と 検証モデル（任意）を指定します。メインモデル が一次読取を担当し、検証モデル を設定すると別モデルで同一項目を再読取し、結果を照合します。候補は モデル設定 の 用途割当 で OCR 抽出用途に 有効 化した接続のみ表示されます。

人工確認ルール（読取モデル設定） ダイアログ内の 人工確認ルール は固定表示です。自信度がボーダーラインを下回り、複数モデルの読取結果が不一致 の場合、該当フィールドは要確認となり、案件の ocrResult が reviewRequired になります。業務シーンのワークフローで OCR 抽出直後の条件分岐（ocrResult = reviewRequired）により OCR 人工確認 タスクが生成され、操作員は マイタスク で確認します。検証モデル を未設定の場合は単一モデル読取となり、不一致照合は行われません。
