業務操作モジュール

マイタスク

ワークフローで生成されたタスクの一覧・実行入口です。OCR 抽出確認、AI 検証確認、エクスポート の 3 種類を扱います（前処理確認タスクは本期対象外）。OCR / AI 検証の実行画面では、ワークフロー上の 人工確認 ノードに対応する OCR 抽出完了・AI 検証完了、補件、案件中止 が出口として連動します。

操作ポイント

1未対応 / 対応済 でタスクを切り替え、タスク種別・案件キー・業務シーン・業務 key で絞り込みます。未対応行の 対応 で実行ページへ進みます。

2OCR 抽出確認 — 帳票画像と抽出結果を対照しながら修正します。

2.1 一覧の 対応 から実行画面を開きます。左に帳票プレビュー、右に テキスト読取 / テーブル情報読取 タブがあります。要確認フィールド数は帳票タブのバッジと右上の 要確認 件数で確認できます。
2.2 テキスト読取 タブで各フィールドの切图と入力値を確認します。項目位置を非表示 を ON にすると、右側にフィールド切图が表示され、入力框をクリックすると左の帳票上で対応領域がハイライトされます（左右連動）。エラー箇所のみ表示・一括確認 で要確認項目を絞り込めます。
2.3 テーブル情報読取 タブで明細行（例：振込先指定口座）を確認・修正します。行単位で 確認待ち 状態を解消します。
2.4 Master 照合フィールドでは、完全一致しない場合に 類似度検索 候補が表示されます。候補を選んで正規値に置き換えます。
人工確認ノードとの連動（OCR / AI 検証共通） 実行画面フッターの OCR 抽出完了 / AI 検証完了 は、ワークフロー画布上の 人工確認 ノードの 完了 出口に対応し、後続ノードへ進みます。補件 は 補件 出口へルーティングされ、画布で設定した前序ノード（例：前処理・OCR 抽出）へ回流します；案件は 補件 状態となり、案件一覧 から追加書類をアップロードします。案件中止 は 案件中止 出口に対応し、現在のワークフローインスタンスを終了します（案件自体は再実行可能）。保存 は進捗のみ保存し、出口は確定しません。

3操作管理者は一覧の 割当 で タスク割当 ダイアログを開き、担当者を変更できます（案件一覧 の案件担当者改派とは独立）。

4AI 検証確認 — 帳票タブまたは AI 検証要約結果 タブで検証結果を確認します。

4.1 完備性 モジュールで 欠損帳票（必要書類の不足）と 欠損フィールド（必須項目の未抽出）を確認します。帳票名・フィールド名をクリックすると該当帳票タブへ移動できます。
4.2 データ検証 でルール式の判定結果と検証フィールドの値を確認します。確認済み / 確認待ち で状態を更新します。
4.3 印鑑・署名検証 で対象帳票・検出対象・照合先フィールドを確認します。帳票名リンクから該当帳票のプレビューへ遷移できます。

5エクスポート — ワークフロー完了後の出力タスクです。エクスポート設定 で定義した項目・条件に沿って内容を確認し、提出して案件を エクスポート済 にします。
