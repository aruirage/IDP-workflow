ルール設定モジュール

AI検証設定

本モジュールでは、AI検証ルールを設定します。業務ルール設定 → AI検証設定 を開き、6 つの Tab でルールを管理します。適用シーンを先に選んでから帳票タイプ・フィールドを指定する点は、データマッピング設定 と同じです。

操作ポイント

1必須フィールド — ルール一括追加 で 適用シーン、帳票タイプ、フィールド を選び、挿入 で 選択フィールド に追加して 追加 します。標準変数を対象にする場合は 標準フィールド を はい に切り替えます。追加後は ルール一覧 に反映され、行の 削除 で無効化できます。

2必要書類 — 業務シーン を選び、案件に必要な帳票タイプを 必須 または 任意 に設定します。保険金請求では、診断書・保険金請求書・診療明細書などの提出有無を案件単位で確認します。

3標準データ整合性 — データマッピング設定 で参照元が 2 件以上ある標準変数が一覧表示されます。データ整合性検証 スイッチを ON にすると、同一標準変数に紐づく OCR 値の一致を検証します。マッピング自体はデータマッピング設定で編集します。

4テキスト検証 — ルール追加 で 適用シーン、ルール名、ルール記述 を設定します。フィールド参照は 挿入 で {{帳票タイプ.フィールド名}} 形式のトークンを書き込み、少なくとも 1 件の有効なフィールド参照が必要です。必要に応じて AIルール最適化 を使い、ルール一覧 の 編集 で内容を更新します。

5データ検証 — 数値・日付・期間・合計などの構造化データを、算術式または自然文 + フィールドトークンで検証します。入院期間、請求日、点数合計など、帳票間の整合性確認に使います。AIルール最適化 で式の整理も可能です。

6署名・印鑑検証 — 適用シーン、ルール名、対象帳票、検出対象（印影／署名／両方）、必要に応じて 照合先 を設定して 追加 します。各ルールは 状態 スイッチで個別に ON/OFF できます。

適用ルール AI検証ルールは、業務シーン設定 の ワークフロー設定 内にある AI検証 ノードで適用されます。ノードで有効な検証種別のみ実行され、実行時は verifyStatus、verifyResult、逐条ルール結果を出力します。要確認の結果はワークフロー条件に従って マイタスク の AI検証確認待办に起票されます。
