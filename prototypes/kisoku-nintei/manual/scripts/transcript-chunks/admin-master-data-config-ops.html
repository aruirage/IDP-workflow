適用タイミング

表記ゆれの正規化、金融機関・医薬品などの参照表を整備するとき、または帳票タイプで マスタ照合 を使う前に登録します。一括インポート 後は必ず ベクトル化状態 が 完了 になるまで待機してください。

実現効果

マスター表・列設定・照会コード・データ行を管理し、ベクトル化が 完了 した行のみ、OCR 値の照合・正規値書き戻し（ハイブリッド検索 等）の参照元として利用できます。

関連影響

帳票タイプ設定 の マスタ照合 は、ベクトル化 完了 行にのみ有効です。待機中・処理中・失敗 行は照合対象外となり、失敗 は手動で 再実行 が必要です。

インポート後のベクトル化（必須確認） データ登録・一括インポート 直後から、一覧の ベクトル化状態 を継続的に確認してください。状態が 完了 になって初めて、当該行は 帳票タイプ設定 の マスタ照合 で利用可能です。1 万行規模以上ではベクトル化に 30 分以上 かかる場合があります。 失敗 行は操作列 再実行、または一覧上部の ベクトル化再実行 で手動リトライしてください。
