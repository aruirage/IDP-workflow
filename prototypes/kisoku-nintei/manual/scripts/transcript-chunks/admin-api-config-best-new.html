ルール設定モジュール

API設定

Open API のエンドポイントと API Key を管理します。通知 URL は 業務シーン設定 の 通知設定 で定義します。

操作手順

  1. 業務ルール設定 → API設定 を開きます。
  2. 画面の詳細説明は、別途用意している API 接続文書を参照します。
  3. ここでは API を使う前提だけを確認し、実装や接続手順の詳細は文書側で管理します。
適用ルール API は外部システム連携の入口です。アップロード後に実行される分類、OCR、データマッピング、AI検証、通知、出力ルールは、公開済みの 業務シーン設定 に従います。通知 URL は業務シーン内の 通知設定 で定義されたイベントにより起動し、出力操作そのものでは起動しません。
補足 API の接続先やリクエスト仕様は、このマニュアルではなく API 文書を参照してください。
