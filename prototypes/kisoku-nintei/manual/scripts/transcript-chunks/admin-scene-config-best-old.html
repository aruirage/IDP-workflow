ルール設定モジュール

業務シーン設定

本モジュールでは、帳票タイプ・マスターデータ・データマッピング・AI検証設定を組み合わせ、保険金請求の実行フローを Step1 案件集約 → Step2 ワークフロー → Step3 通知 → Step4 出力・公開 の 4 ステップで構成します。新規・編集・コピーは同一フローです。各ステップの 保存 は下書きのみ更新し、バージョン番号は生成しません。Step2 の 設定チェック 通過後に 公開可能 となり、公開 確認後に正式バージョンが確定します。

操作ポイント

1Step1 — 案件集約ルール：業務シーン名、関連帳票、主帳票・業務キー、帳票間フィールド関係を設定します。

1.1 業務ルール設定 → 業務シーン設定 で一覧を開き、＋ 業務シーン追加・コピー・名称変更・削除、キーワード検索（業務シーン名で検索）を行います。
1.2 業務シーン名（1～64 文字）、説明、+ 帳票追加 で関連帳票（1～20）を選び、主帳票 と 業務キー（主フィールド）を指定します。
1.3 帳票間フィールド関係を Group（A / B / C…）単位で設定します。グループ内は AND、グループ間は OR です。関連プレビューで折りたたみ・拡大表示を確認できます。
1.4 関連チェック で、すべての関連帳票が主帳票に到達できるか確認します。2 帳票以上選択済みなら AI 自動関連付け で関連ルールを生成できます（失敗時は既存ルールを保持）。
1.5 保存 は下書きのみ保存し Step1 に留まります。次へ は必須項目と帳票ネットワークを検証し、問題なければ Step2 へ進みます。

2Step2 — ワークフロー設定：Step1 の帳票・フィールド範囲内でノードと分岐を編成します。

2.1 ワークフロー設定 でキャンバスを開きます。固定の 開始 ノードから、ノードを追加 で処理ノードを配置します。
2.2 前処理、OCR 抽出、データマッピング、AI 検証、条件判断（IF/ELSE）、人工確認、カスタム関数、終了ノードを接続します。データマッピング・AI 検証は設定ページへの参照のみで、ルール本体は各設定モジュールで管理します。
2.3 人工確認は 完了・補件・案件中止 の 3 出口です。補件 は上流ノードへのループバック接続が必要です（設定チェックで検証）。
2.4 保存 はキャンバス下書きのみ保存します（設定チェックは実行しません）。リセット で開始ノード以外を削除できます。設定チェック は静的構成検証を行い、成功時に 公開可能 に更新します。
2.5 次へ で Step3 へ進みます（設定チェックは自動実行されません）。前へ で Step1 に戻れます。

3Step3 — 通知設定：グローバル通知ルールテンプレートを定義します（Step2 キャンバスのノード実例は読みません）。

3.1 通知ルール追加 で 対象ノード（前処理 / OCR 抽出 / データマッピング / AI 検証 / 人工確認）と トリガーイベント、通知対象 を選びます。
3.2 件名・内容を編集し、変数挿入区から caseId やノード出力変数を挿入します。トリガー条件は画面に表示されず、対象ノードの Status / Result または人工確認の 完了・補件・案件中止 で自動判定されます。
3.3 通知ルール一覧 で有効 / 無効、編集、削除を管理します。同一対象・同一イベント・同一通知先の複数ルールも保存できます。実行時は Step2 に対応ノードが存在し、トリガーイベントに一致した有効ルールのみ送信されます。
3.4 保存 で下書きを更新し Step3 に留まります。次へ で Step4 へ進みます（Step2 設定チェックは実行しません）。

4Step4 — 出力項目 と 公開：OCR 出力候補の選択とシーン公開。

4.1 出力項目を設定 で Step2 OCR 抽出が有効な帳票タイプを選び、普通フィールドとテーブル列を選択・並べ替えます。0 件選択も保存できます。候補がない場合は「出力可能な項目がありません」と表示されます。
4.2 保存 で出力選択を下書きに固化します（ワークフロー再検証は行いません）。
4.3 公開 をクリックします。公開可能でない場合は Step2 設定チェック を自動実行し、失敗時は Step2 へ遷移、成功時は確認ダイアログ（業務シーンを公開しますか？）後に正式バージョンを生成します。公開後、新規案件はこのバージョンのみ参照します。
適用ルール 各ステップの 保存 は下書きのみ更新し、バージョン番号は生成しません。Step2 設定チェック 通過で 公開可能 になります。Step3・Step4 の保存は公開ゲートに含まれません。Step4 公開 時、公開可能でなければ Step2 設定チェックを自動実行します。公開済みシーンは 現在の下書き と 適用中 バージョンを切り替えて閲覧できます。Step1 の帳票・フィールド変更は Step2 キャンバスと Step4 出力候補に連動し、後続参照がある場合は保存がブロックされます。
