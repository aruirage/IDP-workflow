業務操作モジュール

マイタスク

ワークフローで生成されたタスクの一覧・実行入口です。OCR 抽出確認、AI 検証確認、エクスポート の 3 種類を扱います（前処理確認タスクは本期対象外）。

操作ポイント

1未対応 / 対応済 でタスクを切り替え、種別・案件キー・業務シーンで絞り込みます。未対応行の 対応 で実行ページへ進みます。操作管理者は 割当 で担当者を変更できます（案件一覧の担当者改派とは独立）。

2OCR 抽出確認 — 影像を参照しながら OCR 項目・明細・マスター候補を修正します。保存 は進捗のみ保存、OCR 抽出完了 でタスクを完了します。補件・案件中止 もここから実行できます。

3AI 検証確認 — 必要書類・必須フィールドと各検証ルールを確認し、要修正・補件・案件中止を判断します。AI 検証完了 でタスクを完了します。

4エクスポート — ワークフロー完了後の出力タスクです。エクスポート設定 で定義した項目・条件に沿って内容を確認し、提出して案件を エクスポート済 にします。
