ルール設定モジュール

データマッピング設定

本モジュールでは、複数の帳票タイプから抽出された OCR 項目を案件単位の標準項目へ整理します。保険金請求のケースでは、証券番号、被保険者名、医療機関名、請求金額などが複数帳票にまたがるため、先に項目の扱いを統一します。

操作ポイント

  1. 案件単位で利用する標準項目を定義します。
  2. 各標準項目に対して、参照元の帳票タイプと OCR 項目を紐付けます。
  3. 複数の帳票項目を参照元にできる場合は、優先度と必要な軽量変換を設定します。
適用ルール データマッピングは、業務シーン設定 の ワークフロー設定 内にある データマッピング ノードで実行されます。項目の競合や業務上の整合性判定は、AI検証ルールで扱います。
