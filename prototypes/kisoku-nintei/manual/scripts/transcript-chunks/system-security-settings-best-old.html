システム設定モジュール

セキュリティ設定

本モジュールでは、データ保存期限とアイドルセッションを設定し、データライフサイクルと無操作時の自動ログアウトを管理します。図では、保存期限、アイドルセッション、保存ボタンの位置を確認します。

操作ポイント

1データ保存期限設定 で、アップロードファイルと認識結果の保存期限を設定します。期限切れ後のデータは復元できません。

2アイドルセッション設定 で、無操作時の自動ログアウト時間を設定します。設定が有効になると、オンラインユーザーには次回ログイン時から新しいポリシーが適用されます。

保存時の注意 データ保存期限を過ぎた読取記録および関連ファイルは、設定に基づき自動削除されます。運用開始前に、業務上必要な保存期間を確認してください。
