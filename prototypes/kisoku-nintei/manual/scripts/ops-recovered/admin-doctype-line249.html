本モジュールでは、帳票タイプごとに分類条件、抽出項目、後処理、効果テストを定義します。非定型帳票では固定位置の标注ではなく、自然言語の プロンプト で AI にデータを探させます。保険金請求では、保険金請求書、診断書、診療明細書、領収書、調剤明細書を順に設定します。

操作ポイント

1帳票タイプを作成 — まず帳票タイプを定義し、AI に当該帳票の業務上の特徴を伝えます。

  1. 帳票設定 → 帳票タイプ設定 を開きます。
  2. 左側リスト上部の + タイプ追加 をクリックし、帳票名を入力します（例：診断書）。
  3. AI分類設定 で代表サンプルをアップロードします（複数ページ PDF 可）。アップロード成功後、AI が帳票の特徴を読み取り 説明文 を自動生成します。内容は編集可能で、混在スキャン時の自動分類に利用されます。
  4. 次へ をクリックして次のステップへ進みます。

2抽出項目を定義 — 核心ステップ。AI読取設定 で、AI への「質問」形式により読取対象を指定します。

  1. + 項目追加 で項目・列名を追加します。AI自動標注 を使うと、サンプル画像から抽出可能な項目とテーブル列を自動生成できます。抽出対象が明確な場合は、保存アイコン（テンプレート）から テンプレートをダウンロード、一括ダウンロード、一括インポート も利用できます。
  2. 項目設定：項目名（必須）、プロンプト（任意。例：「総行名のみ抽出し、支店名は不要」）、正解サンプル（期待出力例。例：1980年1月1日）を入力します。操作列の移動アイコンで、CSV 出力や API JSON の項目・テーブル表示順を調整します。
  3. リストデータを抽出する場合は テーブル情報読取 タブに切り替え、列キー名とプロンプトを定義します。
  4. 設定アイコンから 読取モデル設定 を開き、メインモデル（1 つのみ）と 検証モデル（複数可）を指定します。複数モデルの読取結果が不一致の項目は、帳票読取 の読取確認画面で赤色表示されます。
  5. 抽出対象の項目・テーブル列がすべて定義されたことを確認し、次へ をクリックします。

3データ処理ルールを設定 — 処理ルール設定 で、AI が抽出した非構造テキストを業務システム向けに整形します。

  1. Step2 で定義した各項目に、データ標準化ルールを選択します。AIマッチング をクリックすると、項目名に応じた処理ルールを AI が自動提案します。必要に応じて修正します。
  2. 自信度の初期値は 95.00% です。閾値未満の読取結果は、帳票読取 の読取確認画面で赤色表示されます。

4効果テスト — セマンティック理解モデルの精度を検証します。

  1. ファイル選択 から、Step1 と版式が異なる同一タイプのサンプルをアップロードします。初期サンプルでも構いません。
  2. テスト をクリックします。通常 20 秒程度かかります。
  3. テキスト読取 と テーブル情報読取 の結果を確認します。項目意味の理解（例：発注日と納品日の混同がないか）、データ形式の整形結果を検証します。精度が不足する場合は Step2 の プロンプト を具体化して再調整します（例：「日付を読取」→「ページ右上の発行日を読取」）。

以上の設定後、保存 すると非定型テンプレートが有効になります。以降、帳票読取 画面で 非定型帳票 と対応する 読取文書タイプ を選択してアップロードすると、当該帳票タイプの設定に基づいて AI が高精度に抽出します。

適用ルール 帳票タイプ設定は、ファイルアップロード後の分類、OCR 抽出、人工確認前の処理段階で適用されます。必要に応じて画面の 画像処理設定 で画像分割・画像組合・画像整列も設定できます。項目がデータマッピング、AI検証、出力設定から参照されている場合、削除や名称変更は下流設定に影響します。
