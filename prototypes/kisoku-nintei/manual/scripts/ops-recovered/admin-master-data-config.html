1+ マスター追加 — マスター表の作成

1.1業務ルール設定 → マスターデータ設定 を開き、左側の + マスター追加 でマスター表を作成します（例：医薬品情報、銀行情報）。

2列設定 — 列定義と照会 code

2.1作成したマスターを選択し、列設定 で列名を定義します（最大 10 列、列名の重複不可）。照会コード を付けた列は、マスタ照合および一覧検索で優先的にマッチされます。

3データ登録 — + 項目追加 または 一括インポート

3.1+ 項目追加：一覧先頭に空白行を挿入し、セル入力後に保存すると行が登録されベクトル化が開始されます（列未設定時はボタンはグレーアウト）。

3.2一括インポート：テンプレート取得 → ファイル選択 → 追加更新 / 上書更新。列未設定でもファイルのヘッダーから列構造を取り込めます。1 回の取込上限は 50,000 行（ヘッダー除く）です。

適用ルール 登録・インポート後、各行の ベクトル化状態（旧「AI 分析状態」）に従ってベクトル化が非同期実行されます。完了後、マスタ照合 等から参照できます。
